Profiles

A profile includes its Hue Bridge, Entertainment area, panel groups, brightness and color response. Save or discard drafts before using profiles.

Color response

Smoothing softens changes over time. Saturation 100% preserves the input; 0% gives grayscale. Colors below the black threshold become black immediately. Zero disables the threshold. The swatches preview target colors; diagnostics show the actual smoothed output.

Settings & pairing

Entertainment area

Changing area clears panel groups and individual brightness for the new channels. Save a profile first to preserve the current setup.

Guided connection

Experimental direct Sync+: saving placement in the iPhone Sync+ editor currently removes this virtual receiver from the 4D configuration. Use the virtual On/Off switch for daily control; placement editing on iPhone is not yet supported.

  1. Discover the 4D below and verify its address.
  2. Open the virtual pairing window and add Shapes Hue Bridge in Nanoleaf Desktop on the same LAN.
  3. Use Register receiver in 4D Sync+ in the terminal maintenance menu. The installer also performs this step. iPhone/HomeKit onboarding is unsupported.
  4. Connect Hue, select an Entertainment area and map your lights.

Settings backup

Exports contain configuration and profiles, without access keys, Hue credentials or HomeKit codes. Import replaces current settings and profiles. Export first; use a full system backup or snapshot for complete recovery.

Per-light color response

Overrides global response for this light. RGB gains correct differences between lamps. Brightness is controlled above. Saved overrides are included in profiles and settings exports.

Temporary color test

Works without TV frames, even when synchronization is off. Respects saved brightness and color response. Takes over output temporarily, then resumes the previous mode. Maximum 60 seconds.
