Profiles

A profile includes its Hue Bridge, Entertainment area, panel groups, brightness and color response. Save or discard drafts before using profiles.

Color response

Smoothing softens changes over time. Saturation 100% preserves the input; 0% gives grayscale. Colors below the black threshold become black immediately. Zero disables the threshold. The swatches preview target colors; diagnostics show the actual smoothed output.

Settings & pairing

Entertainment area

Changing area clears panel groups and individual brightness for the new channels. Save a profile first to preserve the current setup.

Guided connection

  1. Keep the 4D and physical Shapes in Sync+, on the container LAN. Use the source devices selected during installation.
  2. Add the virtual Shapes Hue Bridge accessory in the Nanoleaf app using its HomeKit code. Existing pairing is preserved.
  3. Connect a Hue Bridge, press its physical button if requested, then choose an existing Entertainment area.
  4. Select the virtual device in Sync+, start Screen Mirror on the 4D and map your Hue lights above.

Settings backup

Exports contain configuration and profiles, without access keys, Hue credentials or HomeKit codes. Import replaces current settings and profiles. Export first; use a Proxmox snapshot for full recovery.
